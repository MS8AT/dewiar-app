# PATCH-017 — резерв финального запроса Codex

## Проблема

Задача могла израсходовать весь подтверждённый лимит на `project_list` и
`project_read`. После полезного чтения она оставалась `paused`: итоговый файл не
создавался, а план показывал 0 выполненных пунктов.

## Что меняет патч

- заранее считает запрос на итог и включённые этапы самопроверки/урока;
- когда остаётся только этот резерв, разрешает модели лишь `finish` или `pause`;
- передаёт в ограниченный prompt явные поля `requests_remaining` и
  `finalization_reserve`;
- не увеличивает квоту, не делает скрытых повторов и не обходит подтверждение
  дополнительных платных запросов.

## Проверка

Автономный тест воспроизводит лимит 5: два чтения проекта, итог, самопроверка и
урок. Третий запрос уже получает только действия `finish`/`pause`; задача
завершается с `итог.md` и `урок Codex.md` ровно за пять запросов.
