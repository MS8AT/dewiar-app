# План проверки API, CLI и SLI

Цель: проверять каждый слой отдельно. Один блок — одна понятная причина отказа.
Без отдельного разрешения план не отправляет запрос модели, не тратит лимит подписки и не меняет задачи.

## T1. CLI без запущенного Dewiar

Команды: `dewiar-cli.cmd test`, `dewiar-cli.cmd api`.

PASS: exit code `0`, валидный JSON `schema=1`, `model_calls=0`, `network_calls=0`. В `api` допустим только заполнитель `<read from protected file>`, не значение token.

## T2. Живой read-only API

Команды: `status`, `brains`, `journal`, `sli` по три круга.

PASS: все ответы имеют `schema=1` и правильный `action`; события журнала до и после цикла совпадают. Сама диагностика не должна создавать ложные вызовы модели.

## T3. Границы доступа

Проверки: diagnostic hello возвращает только limited scope; неверный token закрывается; чужая команда и неверный `action` отклоняются.

PASS: нет ни token, ни настроек, ни промптов, ни ответов модели. Никакая запрещённая команда не выполняется.

## T4. Корреляция WebSocket

Ответ на команду ждать по её `id`. События `level`, `state` и другие push-сообщения могут прийти раньше reply.

PASS: клиент пропускает несвязанные события и принимает только reply с ожидаемым `id`.

## T5. API карточки задачи

Команда: `task_observe` для существующей задачи.

PASS: `read_only=true`; ID хеширован; видны статус, шаги, квота, heartbeat и Human Memory; нет цели, путей, промптов, ответов, аргументов и имен аккаунтов.

## T6. SLI

Проверки:

- `sampled = completed + failed + interrupted + unknown + running`;
- `success_ratio = completed / (completed + failed)` или `null`, если знаменатель ноль;
- `p50 <= p95`, времена конечны и неотрицательны;
- `availability=not_measured`, `acceptance=unknown` не выдаются за успех.

## T7. Самопроверка приложения

Команда: `self_check`. Для обычного API-профиля допустима сетевая проверка `/models`. Для Codex по подписке — только локальная проверка аккаунта, модели, согласий и `local_only`; inference не отправляется.

## T8. Журналы

Перед и после каждого блока сравнить размер и время `ui.log`, `core.log`; по новому хвосту считать `Traceback`, `Exception`, `ERROR`, `CRITICAL`, `FATAL`. Старые строки не считать ошибками нового прогона. Содержимое с секретами не печатать.

## T9. Платный/live контур

Отдельный опциональный блок: один короткий inference и одно чтение Human Memory MCP. Запускать только после явного согласия; в общий PASS без этого блока не включать.

## T10. Выбор модели подписки

Явно нажать «Получить модели аккаунта» и проверить число доступных моделей без генерации. После выбора подписочного профиля перезапустить Dewiar и проверить свежий хвост журнала.

PASS: список получен только по кнопке; выбранная модель входит в список; обычная фоновая проверка tools не запускается для `chatgpt_subscription`; в журнале нет ложных сообщений «выберите аккаунт и модель» или «разрешите отдельный маршрут».
