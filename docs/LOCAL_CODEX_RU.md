# Локальный режим Codex: экспериментальное дополнение

Это кандидат для обсуждения в upstream Dewiar, а не официальный выпуск.
Текущая база: Dewiar 0.40.0, commit `0e5917abf71e6d92a67b013c6fe5031f22a8af74`.
Исходная [лицензия](../LICENSE) и авторство сохранены. Порядок вклада —
[CONTRIBUTING](../CONTRIBUTING.md); форк не означает разрешение продавать
или распространять самостоятельный переименованный продукт.

## Границы

Только личное локальное приложение Windows. Обработка запросов происходит
в OpenAI и может расходовать лимиты подписки или кредиты. Это не бесплатный API,
не сервер для нескольких клиентов и не обход политик организации.
Ограничения app-server auth для коммерческих и размещённых сервисов описаны
в [официальной документации](https://learn.chatgpt.com/docs/app-server#auth-endpoints).

Нужен уже установленный официальный CLI, совпадающий с
[закреплённой версией и SHA-256](../core/subscription_runtime/codex-dependency.json):
`0.163.0-alpha.11.2`. Бинарный файл не поставляется и не скачивается.
Если подходящего файла нет, режим откажет; изменение pin требует отдельной проверки.
Вариант SIWC сохранён для совместимости, но его SDK не входит в этот комплект;
для него отдельно проверяются доступ приложения и лицензия DevKit.

У каждого профиля собственный CODEX_HOME и вход через браузер; токены обслуживает
Codex в защищённом хранилище Windows. Токены основного Codex, Hermes и API-ключи
не копируются. Разные Windows SID разделяют хранилища. Профили одного SID —
логическое разделение, не защита от владельца того же Windows-аккаунта.
Параллельные операции сериализуются системным мьютексом; занятый профиль
не перехватывается и не переносится на другой аккаунт.

## Установка и откат

### Полное обновление старой установленной копии до 0.40.0

Для старой версии используйте `tools/upgrade_local_release.py`: он переносит весь
Windows app-комплект 0.40.0 из закреплённого Git commit вместе с дополнением,
а не только изменённые hooks. Требуется локальный Git checkout этой ветки,
Python 3.12+ и неизменённый `requirements-win.lock` установленного приложения.
Если зависимости различаются, скрипт откажет; Python, библиотеки и системные
настройки он не обновляет. Неизвестные дополнительные файлы не удаляются.

Штатно закройте Dewiar, включая трей. Создайте отдельную локальную папку для
плана и резервной копии; пути ниже замените на свои. План содержит пути и SHA,
не содержимое профилей. Каждый запуск установки требует нового backup.

```powershell
py -3 -B tools/upgrade_local_release.py --mode plan --app "C:\Local\Dewiar\app" --plan "C:\Local\DewiarBackup\plan.json"
py -3 -B tools/upgrade_local_release.py --mode check --app "C:\Local\Dewiar\app" --plan "C:\Local\DewiarBackup\plan.json"
py -3 -B tools/upgrade_local_release.py --mode install --closed --app "C:\Local\Dewiar\app" --plan "C:\Local\DewiarBackup\plan.json" --backup "C:\Local\DewiarBackup\before"
```

План фиксирует фактические файлы текущей установки. До установки просмотрите
его состав и сохраните нужные местные доработки: перечисленные файлы программы
будут заменены версией 0.40.0 с дополнением. Все старые файлы комплекта сохраняются
с квитанцией до первой замены. Настройки, память, CODEX_HOME и токены не входят
в комплект; приложение и модель автоматически не запускаются.

Откат тем же локальным checkout и сохранённым планом:

```powershell
py -3 -B tools/upgrade_local_release.py --mode rollback --closed --app "C:\Local\Dewiar\app" --plan "C:\Local\DewiarBackup\plan.json" --backup "C:\Local\DewiarBackup\before"
```

При сбое не запускайте Dewiar до проверки/отката. Изменённые после установки
файлы автоматически не затираются. Маркер версии заменяется последним.

### Только дополнение на чистой базе 0.40.0

Сначала сохраните нужные изменения своей установленной копии. Этот установщик
принимает только точные исходные файлы 0.40.0: старая версия, прежнее дополнение
или чужие правки будут отклонены, а не затёрты. Не обновляйте рабочую копию
только ради прохождения проверки без отдельного резервного копирования.

Скачайте или клонируйте эту ветку в **локальную** папку. Скрипты с SMB/сетевого
диска не запускайте. Нужен Python 3.12+. Выполняйте из корня локального checkout:

```powershell
py -3 -B tools/install_local_codex.py --app "$env:LOCALAPPDATA\Programs\Dewiar\app"
```

По умолчанию это проверка без записи. Для установки штатно закройте Dewiar,
включая трей. Укажите **новый** каталог резервной копии вне приложения и checkout:

```powershell
py -3 -B tools/install_local_codex.py --mode install --closed --app "$env:LOCALAPPDATA\Programs\Dewiar\app" --backup "$env:LOCALAPPDATA\DewiarModBackups\codex-0396-01"
```

Установщик проверяет SHA-256, ссылки/junction и процессы Dewiar, сохраняет старые
исходники и квитанцию. Настройки, память, аккаунты и ключи не входят в манифест.
При ошибке записи не запускайте приложение до отката той же версией комплекта:

```powershell
py -3 -B tools/install_local_codex.py --mode rollback --closed --app "$env:LOCALAPPDATA\Programs\Dewiar\app" --backup "$env:LOCALAPPDATA\DewiarModBackups\codex-0392-01"
```

Если после установки файлы менялись, откат откажет: сначала разберите конфликт.
Резервная копия остаётся у вас. Обновление Dewiar может заменить эти hooks —
не применяйте старый манифест поверх другой версии.

## Использование

Несколько именованных профилей, выбор моделей по контурам и локальный журнал/heartbeat:
[BRAINS_HEARTBEAT_RU.md](BRAINS_HEARTBEAT_RU.md). Права каждого Codex-профиля независимы.

Диагностика: [CLI/API/SLI](DIAGNOSTICS_API_RU.md). Обновление форка:
[текущее ограничение и план автообновления](FORK_AUTOUPDATE_PLAN_RU.md).
Обычный upstream-установщик в этой сборке заблокирован, чтобы не затереть дополнения.
Доверенный автоматический канал пока не настроен; ручной проверяемый installer остаётся.

1. В настройках «Мозг» добавьте профиль подписки и выберите отдельный режим Codex.
2. Нажмите «Проверить установку без сети». Это не тест доступа к модели.
3. Явно выполните вход в новый аккаунт, затем получите модели и выберите модель.
4. Подтвердите отправку текущего текста и проверку Usage; сделайте профиль активным.
5. Включайте дополнительные разрешения только по необходимости:

| Разрешение | Данные и действия |
| --- | --- |
| История | До трёх пар сообщений этого профиля за текущий сеанс, без общей истории. |
| Чтение памяти | До 2500 символов памяти Dewiar «Обо мне», отправляемых в OpenAI. |
| Запись памяти | Только точный факт после отдельного локального подтверждения. |
| Фоновые задачи | Отдельное подтверждение запуска; исходно 1–20 запросов, лимит и использованные попытки сохраняются. После исчерпания — отдельное подтверждаемое продление, общий предел 100. |
| Чтение проекта | Ограниченные текстовые фрагменты выбранного человеком проекта. |
| Самопроверка задач | Дополнительный запрос в том же лимите задачи; не независимая приёмка. |
| Уроки задач | Ещё один запрос в том же лимите; только локальный черновик урока этой задачи. |
| Вспомогательные запросы | Создание инструкций и оценка тестовых сценариев; подготовленный текст может включать контекст разговора и памяти. |
| Встречи | Суфлёр и итоги: расшифровка, материалы и знания встречи; автоматические подсказки регулируются настройками встречи. |
| Дневник | Материалы дня, память и персонаж по расписанию дневника; обычный модуль дневника сохраняет результат. |

Новые разрешения выключены по умолчанию. Самопроверка и уроки требуют также
соответствующих общих переключателей задач. Все дополнительные запросы могут
расходовать лимит подписки. Разрешение дневника/встречи допускает запросы этого
контура без отдельного диалога на каждый вызов — включайте осознанно.

Для задач нажмите «Выбрать этот профиль для задач». Это не запускает существующие
задачи. Изменение аккаунта, модели или разрешений останавливает текущий запрос;
для старой привязанной задачи создайте новую. Проекты с закрытыми данными
не выбирайте: фильтры известных секретных путей и шаблонов не являются полной DLP.
Память Human/Hermes и семантическая память **не подключены автоматически**.

Подтверждение запуска задачи и записи факта теперь показывается также в студии,
не только в виджете. Если задача пишет «Ожидаю подтверждения запуска», ответьте
на вопрос сверху окна; перезагрузка студии восстанавливает ожидающий вопрос.
Поздний или повторный ответ на уже закрытый вопрос не принимается.

Если лимит задачи исчерпан, вместо бесполезной кнопки «Продолжить» появляется
«Выдать ещё N запросов». Выдача требует отдельного локального подтверждения,
может расходовать лимит подписки или кредиты и записывается в журнал. Она не
сбрасывает число попыток, не вызывает модель и не запускает задачу: после выдачи
человек отдельно нажимает «Продолжить». За одну выдачу можно добавить 1–20,
общий лимит одной задачи — 100 запросов.

Основной чат, ограниченные задачи, их самопроверка/урок и перечисленные текстовые
контуры используют выбранный профиль без автоматического перехода на HTTP API.
Неизвестный потребитель, вложения/изображения, удалённые каналы и старые
неограниченные агентские сценарии остаются закрытыми, а не считаются подключёнными.
При смене профиля или разрешений старый ответ не принимается; ошибок не повторяем.

Нативные инструменты Codex, shell, MCP, plugins, hooks, web и subagents отключены.
Dewiar принимает только один небольшой JSON-план действия за шаг. Запись файлов
проекта и запуск кода не разрешены. Задача может записать свой план/блокнот/итог,
но завершение модели не означает независимую проверку результата.

## Ошибка «Codex вернул недопустимое действие»

Это отказ локального валидатора ответа, а не доказательство проблемы входа.
Ранее все причины выглядели одинаково. Теперь схема ограничивает число и имена
действий, запрос явно описывает формат, а ошибка показывает безопасный код:
`response_json`, `action_name`, `arguments_type`, `arguments_fields` и другие.
Содержимое ответа и памяти в диагностике не сохраняется.

Например, `arguments_values` означает, что аргументы не являются непустыми
строками допустимого размера; номер строки тоже передаётся строкой.
Неверный ответ не исправляется догадкой, не выполняется и не повторяется.
Предыдущие успешно завершённые шаги задачи при этом не отменяются.
Без фактического отклонённого ответа причина конкретного старого случая неизвестна.

## Проверка

```powershell
py -3 -B tests/subscription_suite_test.py
```

Нужны Python и Node.js. Только синтетические данные, без входа, модели и реальной
памяти. На Linux Windows ACL/DPAPI-тесты явно пропускаются. Набор также включён
в `tests/run_quick.sh` и `tests/run_all.sh`.
Офлайн-проверка CLI — `core/subscription_runtime/probe_codex.py`: новый пустой
профиль, только initialize/config/read, без model/list и inference.
Живой вход, ответы моделей, визуальная приёмка и установка на рабочий ПК —
отдельные проверки, не доказанные unit-тестами.
Фактические результаты и оставшиеся проверки — в
[отчёте кандидата](LOCAL_CODEX_VALIDATION_RU.md).

## Что сохранено из обновления

База содержит все изменения 0.39.0–0.40.0, а не отдельную выборку.
Среди них: размеры/масштаб блокнота, исправления длинной голосовой просьбы,
второго монитора и смены микрофона; перезапуск ядра Windows после обновления,
проверка SHA-256 Python и исправления облачных ошибок 400/сети Android.
Подробности и авторство — в [upstream CHANGELOG](../CHANGELOG.md).
В 0.39.2–0.40.0 добавлены улучшения блокнота, отдельные разговоры персонажей,
возврат неотправленного сообщения после потери ядра, системные сертификаты Windows,
английский голос, встречи на компьютере и исправления фоновых задач. Ранее добавлены перетаскивание окна за блокнот, ползунок размера текста
и прямой запрос обновления без модели. В режиме подписки ранняя изоляция
текста сохраняется: обновления проверяйте отдельной кнопкой «О программе»,
а не обещанием модели; обычный маршрут команды upstream не меняется.
Повторы обычных провайдеров не включаются для маршрута подписки.

Следующий отдельный этап — [план изоляции WireGuard](WIREGUARD_ISOLATION_PLAN_RU.md).
